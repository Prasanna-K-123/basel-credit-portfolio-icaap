# ICAAP-style framework

The repository separates five questions that a credit-risk / capital team must answer:

1. **What is the portfolio's normal-course risk?** Expected loss and Basel-style unexpected-loss capital.
2. **How severe is tail loss under correlated defaults?** 99%/99.9% loss distribution and economic capital.
3. **Where is risk concentrated?** Single-name, sector and geographic EAD concentration.
4. **How does capital behave under deterioration?** PD/LGD/EAD stress scenarios plus reverse stress.
5. **Is the internal capital buffer sufficient?** A transparent capital stack combining core credit risk, concentration and stress overlays.

The output report is designed to read like an analytical risk committee pack, while keeping every non-empirical assumption explicitly labelled.
